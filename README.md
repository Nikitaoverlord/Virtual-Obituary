## Virtual Obituary (2042-25)
# The Problem
<img width="256" height="256" alt="logo" src="https://github.com/user-attachments/assets/593cc152-60fa-4614-bc5d-1de539112b32" />
The need for a virtual obituary/memoriam has been more and more necessary as there are many complications with physical ones.
People want an obituary that can be shared with others easily and can last for a very long time. 
Physical obituaries can’t store audios or links either 

# Objective
 - A multi-page website with different subdomains to navigate for each profile.
 - Look very nice and presentable. Use AI like to help us code an aesthetic frontend page.
 - Each profile must have audio files, text, images, and interactive notes.

## Features
 - Create profile through web forum with image, description, audio, and notes (a link to shared google doc that can have annotations from multiple people)
 - Scower through the different the list of profile to learn more about different people! Information between users and server is exchanged with socket.io regularly.
 - Or use the search engine
 - Secure login (saves to datafiles for future use)

## Languages and Tools
- JavaScript
- HTML/CSS
- Express
- Socket.IO
- Custom web design with some generative AI assistance
