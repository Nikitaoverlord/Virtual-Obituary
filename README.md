## Virtual Obituary (2042-25)
# The Problem
The need for a virtual obituary/memoriam has been more necessary as there are many complications with physical ones:
 - People want an obituary that can be shared with others easily and can last for a very long time. 
 - Physical obituaries can’t store audios or links either 
<img width="100" height="100" alt="logo" src="https://github.com/user-attachments/assets/593cc152-60fa-4614-bc5d-1de539112b32" />

# Objective
 - A multi-page website with different subdomains to navigate for each profile.
 - Look very nice and presentable. Make use of AI like to help code an aesthetic frontend page.
 - Each profile must have audio files, text, images, and interactive notes.
